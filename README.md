#  Patient Readmission Prediction & Healthcare Analytics

This project focuses on analyzing healthcare patient data and predicting the likelihood of **hospital readmission** using data analysis .

The project follows an end-to-end healthcare analytics workflow using **Python, SQL, Machine Learning, and Power BI**.

 This project is intended for educational and portfolio purposes.

 Project Objectives

* Analyze patient healthcare data.
* Identify patterns and factors associated with readmission.
* Perform data cleaning and exploratory data analysis.
* Prepare healthcare data for machine learning.
* Build classification models for readmission prediction.
* Create an interactive Power BI dashboard.
* Present healthcare insights in a clear and business-friendly format.
